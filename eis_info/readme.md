# Проект по анализу закупок (44-ФЗ)

Автоматизированный парсинг и анализ данных с портала ЕИС (zakupki.gov.ru). Данные хранятся в DuckDB, обработка и визуализация – в Jupyter Notebook.

## 📚 Используемые библиотеки

- `jupyter` (lab / notebook) – среда для анализа
- `duckdb` – колоночная база данных
- `aiohttp`, `beautifulsoup4` – асинхронный парсинг
- `pandas`, `numpy`, `matplotlib` – обработка и визуализация
- `plotly` / `ipywidgets` – интерактивные графики

Полный список зависимостей – в файле [`requirements.txt`](requirements.txt).

## 🧹 Проверка качества данных

> 📓 **Блокнот проверки качества данных** – [data_quality_check.ipynb](data_quality_check.ipynb)

- Удаление нецифровых символов из поля `consumers.eis_id`
- Проверка `NULL` в `order_cards` для столбцов:
  `contract_number`, `contract_type`, `placement_date`, `end_date`, `update_date`, `name`, `consumer_id`, `total_price`, `status`
- Сравнение суммы `parser_data.card_amount` (где `is_parsed = true`) с общим количеством записей в `order_cards` – выявлены расхождения (одна из причин – источники данных)
- Проверка наличия записей с `is_parsed = false`
