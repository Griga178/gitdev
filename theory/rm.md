## БД

- Где хранится: файл `graph.json`

- Структура: 3 списка из словарей (узлы, ребра, типы ребер)
```json
{
  "nodes": [...],
  "edges": [...],
  "edgeTypes": {...}
}
```

- Доступ, изменение: только чтение, 1 пользователь (браузер). В браузере можно работать с бд, изменения хранятся в ОЗУ, после изменений скачать новый файл `graph.json` и поместить рядом с `main.html`.

### Объекты (экземпляры)

#### Узел

```json
{
  "id": "closures",
  "label": "Замыкания",
  "description": "Функции, помнящие окружение",
  "tags": ["python", "functional"],
  "created": "2026-10-09",
  "updated": "2026-10-09"
}
```
| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `id` | string | да | Уникальный идентификатор (латиница, без пробелов) |
| `label` | string | да | Человекочитаемое имя для отображения на графе |
| `description` | string | нет | Тезисное описание темы |
| `tags` | array[string] | нет | Теги для фильтрации (например, `["python", "basics"]`) |
| `created` | string (ISO) | нет | Дата создания записи |
| `updated` | string (ISO) | нет | Дата последнего обновления |

#### Типы Связей

```json
{
  "РАСШИРЯЕТ": "Новая тема дополняет старую",
  "ЧАСТЬ_ОТ": "Иерархия (частное → общее)",
  "ПРИМЕР_ИЗ": "Иллюстрация к теме",
  "ИСПОЛЬЗУЕТСЯ_В": "Применение в другой теме",
  "ПРЕДШЕСТВУЕТ": "Порядок изучения",
  "СВЯЗАНА_С": "Общая связь, если не подходит ничего"
}
```

#### Ребро (связь)

```json
{
  "from": "closures",
  "to": "functions",
  "type": "РАСШИРЯЕТ",
  "note": "Замыкания — частный случай функций",
  "created": "2026-10-09"
}
```

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `from` | string | да | `id` исходного узла |
| `to` | string | да | `id` целевого узла |
| `type` | string | да | Ключ из `edgeTypes` |
| `note` | string | нет | Пояснение к конкретной связи |
| `created` | string (ISO) | нет | Дата создания связи |


## Визуализация

HTML + JS + CSS, **Cytoscape.js**


## Запуск

1. Открыть терминал в папке, где лежит `main.html` (там же — `graph.json`, `script.js`, `style.css`).

2. Запустить локальный HTTP-сервер (например, через Python):

  ```bash
  python -m http.server 8000
  ```

  Если порт 8000 занят — указать другой, например `python -m http.server 8080`.

3. Открыть в браузере:

  ```
  http://localhost:8000/main.html
  ```
